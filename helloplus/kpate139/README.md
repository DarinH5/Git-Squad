# Shopping Assistant Backend

This program is a simple Node.js backend for a shopping assistant. It accepts product search requests and returns information about the requested product in JSON format.

## How to Run

Make sure Node.js is installed, then run:

```bash
npm start

The server will run at http://localhost:3000.
How It Relates to Our Project
Node.js could be used as the backend for our AI shopping agent. It can receive requests from our frontend, communicate with AI and other APIs, and send product information back to the user.
