# Demo Website
Demo website that gives a base layout for what our final product might look like
## How to Run
    - pip install streamlit
    - streamlit run app.py (python -m streamlit run app.py if it doesn't work)

## Why
As streamlit is the frontend framework we decided to use for the project, I thought it would be a good idea to get familiar with the technology.
Through this I:
 - Gained an understanding of basic streamlit concepts
 - Familiarized myself with streamlit's documentation
